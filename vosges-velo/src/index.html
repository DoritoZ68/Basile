Zoomez (molette ou +/−), déplacez la carte en la glissant, puis cliquez à l'endroit exact où partir. Le vélo est posé sur la route, la rue ou la piste cyclable la plus proche, dans son sens.

Jusqu'à 4 joueurs, connectés directement d'un navigateur à l'autre (pair à pair, WebRTC), sans serveur ni compte : il suffit d'échanger deux codes par message (SMS, e-mail, discussion). L'hôte choisit le parcours, le mode et les conditions, puis lance la partie avec « Partir ». En course, le peloton est simulé chez l'hôte.

  1. « Inviter un joueur », puis envoyez-lui le code d'invitation.
  2. Collez le code de réponse qu'il vous renvoie, puis « Connecter ».
  3. Recommencez pour chaque joueur (4 au plus).

Envoyez ce code à l'hôte : la connexion s'établit dès qu'il l'a collé.
